# 🖤 X / Twitter Login Clone

A clean X (formerly Twitter) inspired login and signup page clone built with HTML and CSS.

This project was created as frontend layout practice after completing a larger cinematic landing page project. The main goal here was speed, consistency, and cleaner structure, focusing heavily on flexbox layouts, spacing, typography hierarchy, and recreating a real modern interface as accurately as possible.

Unlike some of my previous projects, this clone was built much faster and with significantly more confidence, showing clear improvement in frontend workflow and layout understanding.
